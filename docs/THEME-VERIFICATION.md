# v0.3.1 主题修复验证

日期：2026-09-21。

原问题：基础样式与 YouTube 局部样式保留固定绿色；深色覆盖规则遗漏总览数字，形成深底深字。现在基础样式全部使用颜色变量，五种预设统一控制强调色与侧边栏，工作区和文字使用独立的明暗中性色。警告和信息保留各自的语义配色。

## 验证结果

- Vue / TypeScript 类型检查和 Vite 生产构建通过。
- `cargo build --release -p u2bup-desktop -p u2bup-server --locked` 通过；Windows 便携包包含新版内嵌前端及 FFmpeg / FFprobe。
- 本机浏览器逐一切换森林、海洋、紫罗兰、琥珀、玫瑰的浅色与深色，共 10 组。读取实际计算样式，确认导航高亮、总览图标、按钮随预设变化。
- 总览数字、说明文字与卡片背景的实际对比度：浅色分别为 16.15:1 / 5.64:1；深色分别为 14.26:1 / 8.08:1。
- 五种主题的按钮文字对比度：浅色最低 5.41:1，深色最低 8.78:1。静态调色板检查另涵盖次级底色、主题淡底、按钮悬停及警告/信息配色，抽查的全部组合至少 4.5:1。
- 实际浏览素材库、83 个直播间卡片、后处理管线、任务中心、YouTube 表单和外观设置；查看深色素材库及 YouTube、浅色素材库截图。
- 刷新后保留紫罗兰主题，恢复测试前的「跟随系统」偏好。
- 基础 CSS 无硬编码颜色，样式引用的颜色变量均已定义；`git diff --check` 通过。

本次只修改主题与版本信息，未执行上传、扫描、合并或标题变更。服务更新前确认没有扫描或上传任务，现有合并任务已完成。未重新运行媒体业务测试，也未在 macOS/Linux 桌面实际验证。
